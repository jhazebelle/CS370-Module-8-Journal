# CS370-Module-8-Journal

Project Overview

For this project, I developed an intelligent pirate agent that learns how to navigate a maze and reach a treasure using deep Q-learning. I was provided with the maze environment, experience-memory functions, neural network setup, and supporting code used to display and test the game. My main responsibility was completing the Q-training algorithm. I created the training loop that allows the pirate to explore the maze, select valid actions, store its experiences, learn from previous outcomes, and gradually improve its decisions. After training, the agent successfully completed the maze from the required starting positions.


What Do Computer Scientists Do, and Why Does It Matter?

Computer scientists use algorithms, data, and software to solve problems that may be difficult, repetitive, or too large for people to handle manually. Their work is not limited to writing code; it also involves understanding a problem, evaluating possible solutions, testing results, and considering how the technology will affect others. This project demonstrates that process because the goal was not simply to move a pirate across a maze. I had to design a system that could learn from experience and make better decisions over time. The same concepts can be applied to robotics, transportation, recommendations, inventory management, and other real-world problems.


How Do I Approach a Problem as a Computer Scientist?

I approach a problem by first defining the goal, constraints, available information, and expected outcome. I then divide the larger problem into smaller pieces that can be implemented and tested individually. In this project, that meant understanding the maze’s states, legal actions, rewards, penalties, and completion conditions before working on the training process. I used an iterative approach by running the model, reviewing its results, and checking whether the agent could consistently reach the treasure. This course also taught me that the best algorithm depends on the problem. Traditional programming works well when the rules and correct actions are already known, while machine learning and reinforcement learning are useful when a system needs to identify patterns or improve through experience.


What Are My Ethical Responsibilities?

As a computer scientist, I am responsible for considering more than whether a program technically works. I need to protect user privacy, secure collected information, test for hidden bias, communicate a system’s limitations, and avoid presenting an AI model as more reliable than it actually is. I also have a responsibility to the organization to create maintainable and well-documented software, use data legally, and identify risks before a system is released. These responsibilities often overlap because trustworthy technology protects both the people using it and the organization developing it. Even though this project uses a fictional pirate, the same learning methods could influence decisions in real applications, so accuracy, transparency, safety, and human oversight should be considered throughout development.
